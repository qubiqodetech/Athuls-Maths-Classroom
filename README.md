## 🎯 Project Overview

Athul's Maths Classroom (AMC) is the flagship digital presence for a leading educational institution in Kerala. It aims to transcend traditional educational websites by delivering an enterprise-grade, highly polished, and cinematic user experience. 

### Why It Exists
The traditional educational website landscape is saturated with generic templates. AMC requires a digital platform that reflects the premium quality of its teaching, communicating trust, excellence, and modern pedagogy to parents and students.

### Who It Is For
- **Students**: Seeking an intuitive platform to discover courses, view faculty, and access resources.
- **Parents**: Evaluating the institution's credibility, reviewing testimonials, and submitting admissions inquiries.
- **Educators**: Showcasing their expertise and teaching philosophy in an elegant format.

### Core Goals
- **Business Value**: Increase enrollment through a conversion-optimized user experience and build undeniable brand authority.
- **Technical Value**: Establish a robust, CMS-ready, scalable architecture that can effortlessly support a future student portal, blog, and e-learning integration.

<hr />

## ✨ Features

### 🚀 Core Features
- **Premium Preloader**: An Apple-inspired cinematic preloader sequence.
- **Dynamic Routing**: Seamless navigation across diverse sections (Courses, Faculty, Results).
- **Responsive Architecture**: Flawless execution across Mobile, Tablet, and Ultra-wide Desktop displays.

### 🎨 UI Features
- **Glassmorphism & Depth**: Subtle, refined use of blurs and shadows.
- **Typography-Driven Design**: Hierarchy established through `Sora` and `Inter` font pairings.
- **Sticky Storytelling**: Scroll-driven sticky layouts for deep engagement.

### ⚡ Performance Features
- **Next.js App Router**: Optimized server-first rendering.
- **Lazy Loading**: Viewport-triggered component mounting via `motion/react` and `IntersectionObserver`.
- **Image Optimization**: Fully automated `next/image` pipelines with shimmer placeholders.

### ♿ Accessibility Features
- **WCAG 2.2 AA Compliant**: High contrast ratios and semantic HTML.
- **Keyboard Navigation**: Fully traversable via `Tab`.
- **Reduced Motion Support**: Respects OS-level accessibility preferences.

### 🛡️ Security & SEO
- **Structured Data**: JSON-LD Schema integration for Organizations, Courses, and FAQs.
- **Security Headers**: Configured XSS, Frame, and Content-Type protections.
- **Robots & Sitemaps**: Automated generation for optimal crawling.

### 🛠 Developer Features
- **Strict TypeScript**: End-to-end type safety.
- **Component Driven**: Atomic and modular architecture.
- **Linting & Formatting**: Pre-configured ESLint rules.

## 📂 Folder Structure

```text
ai-studio-applet/
├── docs/                      # Documentation (Design System, CMS Integration)
├── public/                    # Static assets (images, icons)
├── src/
│   ├── animations/            # Shared Framer Motion variants & utilities
│   ├── app/                   # Next.js App Router pages and layouts
│   ├── components/
│   │   ├── courses/           # Course-specific components
│   │   ├── faculty/           # Faculty-specific components
│   │   ├── layout/            # Global structural elements (Navbar, Footer)
│   │   ├── performance/       # Optimization wrappers (LazyLoad, WebVitals)
│   │   ├── preloader/         # Cinematic opening sequence
│   │   ├── scroll/            # Scroll progress and spy components
│   │   ├── sections/          # High-level section components
│   │   ├── seo/               # JSON-LD Schema and meta components
│   │   ├── transitions/       # Global page transitions
│   │   └── ui/                # Atomic UI components (shadcn)
│   ├── config/                # Site configuration and global constants
│   ├── data/                  # Static data models (prepared for CMS)
│   ├── hooks/                 # Reusable React hooks
│   ├── lib/                   # Utility functions (cn, etc.)
│   └── types/                 # Global TypeScript interfaces
├── .eslintrc.json             # ESLint configuration
├── next.config.ts             # Next.js configuration
├── tailwind.config.ts         # Tailwind theme and plugins
└── tsconfig.json              # TypeScript compiler options
```

### Architecture Decisions
- **Feature-first organization**: Components are grouped by domain (`courses`, `faculty`) rather than technical type, scaling better as the project grows.
- **Separation of concerns**: Data logic (`src/data`) is isolated from presentation, paving the way for headless CMS integration.

## 🎨 Design System

The Athul's Maths Classroom Design System is built to enforce consistency, premium aesthetics, and accessibility.

### Colors
- **Primary Navy (`#0D1B2A`)**: Represents authority, trust, and academic excellence.
- **Primary Red (`#E31E24`)**: Adds urgency, passion, and a distinct brand voice.
- **Charcoal (`#1F2937`)**: Used for high-contrast reading text.

### Typography
- **Headings**: `Sora` - A geometric, modern sans-serif that commands attention.
- **Body**: `Inter` - Highly legible, neutral sans-serif designed for computer screens.

### Spacing & Layout
- Based on a comprehensive **8px scale** (`4, 8, 12, 16, 24, 32...`).
- Max container width set to `1440px` with content clamped to `1280px` for optimal reading width on ultra-wide screens.

### Animations
- **Curve**: `[0.16, 1, 0.3, 1]` (Apple-esque, highly polished spring).
- **Duration**: `0.6s` for macro layout shifts, `0.3s` for micro-interactions.

*For full details, reference `docs/DESIGN_SYSTEM.md`.*

## 🎬 Animations

Animation in AMC is functional, not decorative. It guides attention and provides spatial context.

- **Cinematic Preloader**: A session-cached entrance sequence that builds brand anticipation.
- **Page Transitions**: Smooth fade and blur reveals orchestrated through `AnimatePresence`.
- **Scroll Reveals**: Elements naturally enter the viewport using Intersection Observers, staggered for rhythmic flow.
- **Micro-interactions**: Hover states utilize scale and subtle shadow manipulation to ensure tactile feedback.

<hr />

## 🧩 Component Architecture

- **Atomic UI (`/ui`)**: Low-level, generic components like `Button`, `Input`, `Dialog`.
- **Domain Components (`/courses`, `/faculty`)**: Complex, composed elements tailored to specific business logic.
- **Layouts (`/layout`)**: Global wrappers (`Navbar`, `Footer`, `GlobalSearch`) that persist across routes.
- **Performance Wrappers (`/performance`)**: Context boundaries and lazy loaders (`LazyWrapper`, `ImageOptimizer`) that protect the critical rendering path.

<hr />

## ⚡ Performance

Achieving a **95+ Lighthouse Score** is a strict requirement.

- **Image Optimization**: `next/image` handles WebP conversion, responsive sizing, and CLS prevention.
- **Code Splitting**: Heavy components (e.g., Carousels, Video Players) are dynamically imported.
- **Server Components**: The App Router guarantees minimal JavaScript payloads by defaulting to server-rendered HTML.
- **Bundle Analysis**: Monitored via `@next/bundle-analyzer` on the `npm run analyze` script.

<hr />

## 🔍 SEO

Search Engine Optimization is deeply integrated:

- **Dynamic Metadata**: The `generateMetadata` API powers unique titles, descriptions, and OpenGraph tags per page.
- **Structured Data**: JSON-LD (`BreadcrumbSchema`, `OrganizationSchema`, `CourseSchema`) is injected natively for rich snippets.
- **Sitemap & Robots**: Automated `sitemap.ts` and `robots.ts` ensure deep, reliable crawling.

<hr />

## ♿ Accessibility

- **Semantic Markup**: Proper usage of `<nav>`, `<main>`, `<article>`, and `<section>`.
- **Keyboard Navigation**: All interactive elements are fully focusable (`Focus Visible`).
- **ARIA Attributes**: Screen reader support for complex widgets (Accordions, Dialogs).
- **Reduced Motion**: The `useReducedMotion` hook automatically disables heavy animations for users with motion sensitivity.

## 🚀 Installation

Follow these steps to set up the project locally.

### Prerequisites
- Node.js >= 18.x
- npm >= 9.x
- Git

### 1. Clone the repository
```bash
git clone https://github.com/your-username/athuls-maths-classroom.git
cd athuls-maths-classroom
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup Environment Variables
```bash
cp .env.example .env.local
```
*(Populate `.env.local` with your specific keys)*

### 4. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

## ☁️ Deployment

The project is natively optimized for **Vercel**.

1. Push your code to a GitHub repository.
2. Import the project in Vercel.
3. Vercel automatically detects the Next.js framework and configures build commands.
4. Add your Environment Variables in the Vercel Dashboard.
5. Deploy.

*Note: For self-hosting via Docker or alternative PaaS, ensure you run `npm run build` and expose port `3000` via `npm run start`.*

## 🔌 CMS Integration

While currently utilizing static data arrays (`src/data`), the architecture is decoupled to allow seamless migration to a Headless CMS (Sanity, Payload, or Contentful).

- The Data Layer is isolated.
- Types match expected CMS schema structures.
- Image domains can be easily whitelisted in `next.config.ts`.

## 🔄 Git Workflow

- **`main`**: Production-ready code.
- **`develop`**: Integration branch for new features.
- **Feature Branches**: Branch from `develop` using `feat/feature-name` or `fix/bug-name`.
- **Commits**: Follow Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`).

<hr />

## 📏 Coding Standards

- **TypeScript Strict**: `any` types are prohibited. Interfaces over types where applicable.
- **Server Components**: Keep components as Server Components by default. Use `'use client'` strictly at the leaf nodes.
- **Tailwind Sorting**: Use Prettier plugin for automated class sorting.
- **Modular Imports**: Utilize `@/` alias paths.
