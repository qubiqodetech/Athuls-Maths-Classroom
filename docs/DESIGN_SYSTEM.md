# Athul's Maths Classroom - Design System

## Colors

- **Primary Navy**: `#0D1B2A`
- **Primary Red**: `#E31E24`
- **Dark Background**: `#050816`
- **Charcoal**: `#1F2937`
- **White**: `#FFFFFF`
- **Light Gray**: `#F8FAFC`
- **Border**: `#E5E7EB`

### Semantic Colors
- **Success**: `#16A34A`
- **Warning**: `#F59E0B`
- **Error**: `#DC2626`

## Typography

### Headings (Sora)
- Hero: `text-5xl md:text-6xl lg:text-7xl`
- Section Title: `text-3xl md:text-4xl lg:text-5xl`
- Card Title: `text-xl md:text-2xl`

### Body (Inter)
- Large: `text-lg md:text-xl`
- Medium: `text-base`
- Small: `text-sm`

## Spacing Scale
Uses standard Tailwind CSS spacing (4px base):
`4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128`

## Animation Curves
- **Default**: `ease: [0.16, 1, 0.3, 1]` (Spring-like, highly polished)
- **Durations**: Standard `0.6s` for large section reveals, `0.3s` for micro-interactions.

## Shadows & Elevation
- **Level 1 (Cards)**: `shadow-md`
- **Level 2 (Hover)**: `shadow-xl`
- **Level 3 (Floating/Sticky)**: `shadow-lg`

## Border Radius
- Buttons/Small Elements: `rounded-full` or `rounded-md`
- Cards: `rounded-2xl` or `rounded-3xl`
